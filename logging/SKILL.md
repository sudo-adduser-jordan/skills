# Logging Skill

## Instructions

Reference: https://loggingsucks.com/

- Configure any default paths to use `./logs/`:
  - `./logs/errors`
  - `./logs/test`
- Use JSONL for log files.
- Pretty print logs.
- Color logs, keys, values, and value types.
