# Ask Skill

## Instructions

- Always use the ask feature when presenting options, choices, or decisions to the user.
- Never present the user options without using the ask feature.
- Do not list options as plain text, markdown lists, or in chat output when the ask tool is available — route them through the ask feature instead.
